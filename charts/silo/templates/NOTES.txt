{{- if .Values.config.auth.bootstrap }}

  On the first start against an empty database, silo mints an admin token
  and an admin user and prints them ONCE to the pod log. Grab them with:

    kubectl logs -n {{ .Release.Namespace }} \
      -l app.kubernetes.io/instance={{ .Release.Name }},app.kubernetes.io/name=silo \
      | grep -A 12 'SILO BOOTSTRAP'
{{- end }}

Then point the CLI at the gRPC port:

    kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "silo.fullname" . }} {{ .Values.service.grpcPort }}:{{ .Values.service.grpcPort }}
    silo login --server http://localhost:{{ .Values.service.grpcPort }}

Package managers use the HTTP port ({{ .Values.service.httpPort }}):

    dnf   {{ .Values.config.publicBaseUrl | default "http://<host>" }}/<repo>/<channel>
    apk   {{ .Values.config.publicBaseUrl | default "http://<host>" }}/<repo>/<channel>/apk/<arch>
    npm   {{ .Values.config.publicBaseUrl | default "http://<host>" }}/<repo>/<channel>/npm
